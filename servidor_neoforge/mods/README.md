# Mods del Servidor NeoForge

Coloca aquí los archivos `.jar` de los mods **NeoForge**.

## Compatibilidad

- **Loader:** NeoForge 21.1.227
- **Java requerido:** Java 21+

## Importante

- **Solo mods NeoForge** (los mods Fabric NO funcionan en NeoForge)
- **No todos los mods existen para NeoForge** — verifica compatibilidad primero
- Todos los jugadores deben tener **los mismos mods instalados**

## Dónde descargar

- https://modrinth.com/ (filtra por NeoForge)
- https://www.curseforge.com/ (filtra por NeoForge)

## No incluido en Git

Esta carpeta está excluida del repositorio porque los mods son muy pesados. Descárgalos según tu configuración.
