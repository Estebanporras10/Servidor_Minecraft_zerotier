# Configuración de Mods (NeoForge)

Los archivos `.toml`, `.json`, `.json5` y otros que van aquí son generados por los mods de NeoForge.

## Cómo funciona

1. Coloca los mods **NeoForge** en `mods/`
2. Inicia el servidor
3. Los mods generan sus archivos de configuración aquí automáticamente

## Importante

- **NO editees los archivos mientras el servidor corre**
- Detén el servidor antes de cambiar configuración
- Los cambios entran en efecto cuando reinicies el servidor

## Diferencia con Fabric

Los mods de NeoForge generan configuraciones similares a los de Fabric, pero **NO son compatibles** entre loaders. Si cambias de NeoForge a Fabric, los mods también deben cambiar.
